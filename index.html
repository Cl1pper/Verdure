🔑 Clé API PlantNet

Comment obtenir une clé gratuite
  1. Crée un compte sur my.plantnet.org.
  2. Dans ton compte, copie ta clé API (offre gratuite : 500 identifications par jour).
  3. Dans les réglages de la clé, autorise le domaine de ton app (ex. verdure-xxx.vercel.app), sinon le navigateur bloque l'appel.
  4. Colle la clé ici et enregistre.
